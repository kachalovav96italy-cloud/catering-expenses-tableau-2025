# Catering Expenses Dashboard 2025

Учебный проект по визуализации данных в Tableau Public. Дашборд анализирует catering-заказы за 2025 год: плановые и фактические расходы, превышения плана, структуру заказов по типам и нагрузку на персонал.

## Что показывает дашборд

- KPI: количество заказов, фактические расходы, плановые расходы, разница факт-план, количество заказов выше плана.
- План vs факт расходов: сравнение плановых и фактических расходов по месяцам или по датам выбранного месяца.
- Заказы с превышением плана: таблица заказов, где факт оказался выше плана.
- Количество заказов: структура заказов по типам `сервис` и `доставка`.
- Фактические расходы: расходы по типам заказов.
- Доли по количеству и расходам: сравнение сервиса и доставки.
- Уникальный персонал: количество уникальных сотрудников, задействованных в заказах.

## Интерактивность

В дашборде есть переключатель периода:

- `Год` — графики показывают месяцы 2025 года.
- `Месяц` — графики переключаются на даты внутри выбранного месяца.

Также есть параметр `Выбранный месяц`, который управляет месячной детализацией.

## Данные

Источник данных подготовлен в файле `catering_tableau_data.xlsx`. В нем три листа:

- `events_for_tableau` — основные данные по заказам и расходам.
- `staff_for_tableau` — данные по сотрудникам, задействованным в заказах.
- `extra_expenses_for_tableau` — дополнительные расходы; подготовлены для возможного расширения проекта, в текущей версии дашборда не являются основной частью визуализации.

Важно: поля `plan_amount` и `fact_amount` в этом проекте означают расходы, а не выручку.

## Логика типа заказа

Тип заказа определен эвристически:

- `сервис` — заказ с обслуживанием, где есть официанты/бармены.
- `доставка` — заказ без сервисного персонала, похожий на доставку.

Эта логика используется для сравнения структуры заказов и расходов.

## Как открыть проект

1. Открыть `catering_expenses_dashboard_2025.twb` в Tableau Public или Tableau Desktop.
2. Если Tableau попросит путь к источнику данных, выбрать файл `catering_tableau_data.xlsx` из этой же папки.
3. Открыть дашборд с расходами и заказами.

Для полностью самодостаточной версии можно дополнительно сохранить workbook как `.twbx` из Tableau.

## Что отработано в проекте

- Подготовка данных из SQL-проекта для Tableau.
- Работа с несколькими таблицами и связью `заказ - персонал`.
- Calculated fields.
- Parameters.
- Dynamic visibility для переключения год/месяц.
- KPI-блоки.
- Bar-in-bar для план-факт анализа.
- Stacked bar charts.
- Pie charts.
- Компоновка интерактивного dashboard.
