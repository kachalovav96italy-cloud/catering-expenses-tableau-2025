# Data Dictionary

Описание основных полей, использованных в Tableau-проекте.

## events_for_tableau

Одна строка соответствует одному заказу/мероприятию.

| Поле | Описание |
| --- | --- |
| `event_id` | ID заказа. В Tableau переименован в `ID заказа`. |
| `event_date` | Дата заказа. В Tableau переименована в `Дата`. |
| `event_month` | Месяц заказа в формате `YYYY-MM`. |
| `event_month_num` | Номер месяца. Используется для сортировки месяцев. |
| `month_name_ru` | Название месяца на русском языке. |
| `order_type` | Тип заказа: `сервис` или `доставка`. |
| `plan_amount` | Плановые расходы по заказу. |
| `fact_amount` | Фактические расходы по заказу. |
| `fact_minus_plan` | Разница: факт минус план. |
| `is_over_plan` | Признак превышения плана: `true`, если факт больше плана. |
| `over_plan_amount` | Сумма превышения плана. |
| `over_plan_percent` | Процент превышения плана. |
| `manager_name` | Менеджер заказа. |
| `unique_staff_count` | Количество уникальных сотрудников по заказу. |

## staff_for_tableau

Таблица используется для расчета уникального персонала через `COUNTD(employee_id)`.

| Поле | Описание |
| --- | --- |
| `event_id` | ID заказа для связи с `events_for_tableau`. |
| `employee_id` | ID сотрудника. |
| `employee_name` | Имя сотрудника. |
| `employee_type` | Тип сотрудника. |
| `role_name` | Роль сотрудника в заказе. |
| `order_type` | Тип заказа. |
| `event_date` | Дата заказа. |
| `hours_worked` | Отработанные часы. |
| `work_amount` | Выплата за работу. |
| `taxi_amount` | Расходы на такси. |
| `line_total_amount` | Общая сумма по строке персонала. |

## extra_expenses_for_tableau

Таблица с дополнительными расходами. В текущей версии дашборда не используется как основной блок, но оставлена для будущего расширения анализа.

| Поле | Описание |
| --- | --- |
| `event_id` | ID заказа. |
| `expense_category` | Категория дополнительного расхода. |
| `expense_amount` | Сумма дополнительного расхода. |

## Tableau-поля и параметры

| Поле / параметр | Назначение |
| --- | --- |
| `Режим периода` | Параметр переключения между режимами `Год` и `Месяц`. |
| `Выбранный месяц` | Параметр выбора месяца для месячной детализации. |
| `Фильтр режим год` | Показывает годовые листы при выборе режима `Год`. |
| `Фильтр events месяц` | Фильтрует листы на основе `events_for_tableau` по выбранному месяцу. |
| `Фильтр staff месяц` | Фильтрует листы на основе `staff_for_tableau` по выбранному месяцу. |
| `Показать год` | Поле для dynamic visibility годовых листов. |
| `Показать месяц` | Поле для dynamic visibility месячных листов. |
| `Цвет факта` | Поле для окраски факта: в плане или превышение. |

## Допущения

- `plan_amount` и `fact_amount` трактуются как расходы.
- `order_type` определен по признакам персонала и является аналитической эвристикой.
- Данные учебные и используются для портфолио-проекта.
